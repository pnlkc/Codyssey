### 📌 [1] 코딩 없는 마우스 클릭 자동화
* **관련 명세**: `코딩 없이 마우스 클릭만으로 일이 자동으로 돌아가게 만들기`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "코딩을 전혀 모르는 사람이 어떻게 컴퓨터를 시켜 일을 자동으로 처리하게 만드나요?"
* **자가진단 난관 지표**: 복잡한 영어 소스 코드를 타이핑해야만 자동화가 구동된다고 믿어 시작도 하기 전에 포기하려 한다.
* **통과 기준 (이해 완료 판정)**:
  - 마우스를 이용해 화면상에 표시된 기능 블록을 연결하는 방식으로 작동하는 노코드 자동화 개념을 이해한다.
* **퍼실리테이터 개입 가이드**: "인터넷 쇼핑몰에서 장바구니에 물건을 담아 이어 나가는 과정에 비유하며, 간단한 연결 실습을 유도해 노코드 개념을 인지시킨다."

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "코딩 없이 마우스 클릭만으로 일이 자동으로 돌아간다는 게 무슨 뜻인가요? 매크로 같은 건가요?"
* **학습자 난관**: 프로그래밍 소스 코드를 타이핑하지 않고도 마우스 조작만으로 시스템을 구동시킨다는 선언적 약속의 동작 원리를 신뢰하거나 직관적으로 납득하지 못합니다.
* **기본 개념**: 
  - 예전에는 어떤 일을 자동으로 처리하려면 복잡한 영어 명령어를 타이핑(코딩)해야 했음. 하지만 지금은 마치 인터넷 쇼핑몰에서 물건을 고르고 마우스로 장바구니에 담아 선을 잇듯, 화면 상에 표시된 아이콘을 마우스로 클릭해 조립해 놓기만 하면 컴퓨터가 그 설계도대로 알아서 일 처리를 대신하게 만드는 노코드 방식임.
* **퍼실리데이팅 가이드**:
  - 인터넷 쇼핑몰에서 장바구니에 물건을 담아 이어 나가는 과정에 비유하며, 간단한 연결 실습을 유도해 노코드 개념을 인지시킨다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

### 📌 [2] 사무 연동 자동화와 단순 매크로의 차이
* **관련 명세**: `일이 자동으로 돌아가게 만들기 / 반복 업무를 자동화합니다.`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "우리가 배우는 자동화 도구로 만들 수 있는 업무의 예시는 무엇이 있나요?"
* **자가진단 난관 지표**: 자동화의 범위를 게임 봇이나 단순 키보드 반복 매크로 수준으로만 생각한다.
* **통과 기준 (이해 완료 판정)**:
  - 메신저 알림, 스프레드시트 적재 등 서로 다른 클라우드 서비스 간의 API 연동 중심의 자동화임을 설명할 수 있다.
* **퍼실리테이터 개입 가이드**: "단순히 키보드를 흉내 내는 매크로와, 서로 다른 인터넷 사이트들이 데이터를 주고받으며 연동되는 차이를 설명한다."

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "일이 자동으로 돌아가게 만든다는데, 혹시 제 컴퓨터에 게임 자동 사냥 매크로를 돌리는 프로그램도 만들 수 있는 건가요?"
* **학습자 난관**: '자동화'의 범위를 자신이 경험해 본 단편적인 게임 봇(Bot)이나 키보드 반복 매크로 수준으로만 국한 지어 생각합니다.
* **기본 개념**: 
  - 게임 반복 매크로보다는 우리가 직장이나 학교에서 매일 마주하는 '사무용 인터넷 연동 업무'(예: 설문지가 들어오면 메신저로 실시간 비서처럼 알림을 쏘거나, 이메일 내용을 문서에 차곡차곡 받아 적어 정돈해 두는 일)의 자동화에 적합한 도구들을 학습하는 미션임.
* **퍼실리데이팅 가이드**:
  - 단순히 키보드를 흉내 내는 매크로와, 서로 다른 인터넷 사이트들이 데이터를 주고받으며 연동되는 차이를 설명한다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

### 📌 [3] 노코드 자동화의 AI 도구 학습 위계 구조
* **관련 명세**: `분야: AI 도구 학습 / 구분: AI 도구`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "노코드 자동화가 왜 AI 도구 학습이라는 대주제 아래에 포함되어 있나요?"
* **자가진단 난관 지표**: 생성형 AI가 아닌 일반 노코드 툴을 AI 카테고리에서 배우는 이유를 이해하지 못해 혼란스러워한다.
* **통과 기준 (이해 완료 판정)**:
  - 자동화 파이프라인 중간에 생성형 AI(ChatGPT 등)를 액션으로 삽입하여 데이터 가공을 자동화할 수 있음을 인지한다.
* **퍼실리테이터 개입 가이드**: "앞으로 배울 인공지능 비서(ChatGPT 등)를 이 자동화 톱니바퀴에 연결해 자동으로 메일을 요약하게 만드는 기저 지식임을 인지시킨다."

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "코드를 하나도 안 쓰는데 왜 'AI 도구 학습'인가요? 자동화 도구가 인공지능인 건가요?"
* **학습자 난관**: AI 도구 학습이라는 대분류 안에 단순한 노코드 업무 자동화(RPA/Workflow) 도구들이 배치되어 있는 위계 구조에 혼란을 겪습니다.
* **기본 개념**: 
  - 이번 자동화 도구들은 그 자체로 인공지능 비서 역할을 수행하기도 하지만, 보너스 미션처럼 ChatGPT나 Claude 같은 진짜 생성 AI 조수를 이 자동화 톱니바퀴 중간에 끼워 넣어 '이메일을 받자마자 AI가 요약하고 답변 초안을 자동으로 작성하게 만드는' 핵심 파이프라인으로 연결되기 때문에 AI 도구 학습의 핵심 기저 단계로 포함되어 있음.
* **퍼실리데이팅 가이드**:
  - 앞으로 배울 인공지능 비서(ChatGPT 등)를 이 자동화 톱니바퀴에 연결해 자동으로 메일을 요약하게 만드는 기저 지식임을 인지시킨다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

### 📌 [4] 일상 속 반복적인 '루틴 업무'의 정의
* **관련 명세**: `매일 아침 이메일을 확인하고 스프레드시트에 옮겨 적고 팀 채널에 요약을 공유하는 루틴`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "우리 일상이나 업무에서 '루틴'이라고 부를 수 있는 행동에는 무엇이 있나요?"
* **자가진단 난관 지표**: 스포츠나 운동할 때 쓰는 규칙적인 행동으로만 단어의 의미를 좁게 해석한다.
* **통과 기준 (이해 완료 판정)**:
  - 출근 직후 이메일 정리, 복사-붙여넣기 등 규칙적이고 단순 반복되는 업무 절차를 루틴으로 설명할 수 있다.
* **퍼실리테이터 개입 가이드**: "매일 아침 똑같이 반복되는 '이메일 확인 -> 복사 -> 엑셀 입력 -> 공지'와 같은 기계적인 컴퓨터 사용 업무 패턴을 상기시킨다."

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "매일 아침 이메일을 확인하고 요약 공유하는 '루틴'이 정확히 무슨 뜻인가요? 운동할 때 쓰는 말 아닌가요?"
* **학습자 난관**: 스포츠나 피트니스 분야의 '루틴(규칙적인 일련의 행동)' 은유를 업무 프로세스(반복 절차)의 맥락에 매치시키지 못합니다.
* **기본 개념**: 
  - 운동할 때처럼 매일 똑같이 반복하는 규칙적인 동작들을 의미함. 사무 업무에서도 매일 아침 출근하자마자 의식처럼 하는 "이메일 열기 -> 복사하기 -> 엑셀에 붙여넣기 -> 메신저에 공지하기"처럼 지루하고 단순하지만 정해진 순서대로 계속 반복하는 일련의 작업들을 통칭하여 '루틴 업무'라고 부릅니다.
* **퍼실리데이팅 가이드**:
  - 매일 아침 똑같이 반복되는 '이메일 확인 -> 복사 -> 엑셀 입력 -> 공지'와 같은 기계적인 컴퓨터 사용 업무 패턴을 상기시킨다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

### 📌 [5] 자동화 구축의 초기 기회비용과 누적 효과
* **관련 명세**: `한번에 5분이면 끝나는 일이지만 하루에 열 번 반복되면 어느새 50분이 사라집니다.`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "5분짜리 아주 짧은 단순 업무를 굳이 자동화하는 이유는 무엇인가요?"
* **자가진단 난관 지표**: 초기 자동화 세팅에 걸리는 시간을 낭비로 보아, 수작업의 누적 시간 낭비를 간과한다.
* **통과 기준 (이해 완료 판정)**:
  - 초기 학습 비용 대비 매일 반복되어 누적 소모되는 시간 및 주의력 낭비를 차단하는 효과를 정량적으로 납득한다.
* **퍼실리테이터 개입 가이드**: "오늘 1시간 투자해 자동화를 구축하면 앞으로 매달 수십 시간이 복리로 절약됨을 명확히 설명한다."

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "한 번에 겨우 5분밖에 안 걸리는 사소한 일을 굳이 복잡하게 자동화로 만들어야 하는 이유가 있나요? 설정하는 데 시간이 더 오래 걸릴 것 같은데요?"
* **학습자 난관**: 초기 자동화 구축에 드는 학습 및 설계 시간 대비 미래의 업무 효율 누적에 따른 기회비용 절약의 선순환 가치를 체감하지 못합니다.
* **기본 개념**: 
  - 처음 한 번 자동화 톱니바퀴를 세팅하는 데 1~2시간이 걸릴 수 있음. 하지만 한 번 세팅해 두면 하루 50분, 일주일이면 250분이라는 아까운 시간이 영구적으로 절약됨. 사소한 실수를 방지하고 더 가치 있고 창의적인 일에 내 집중력을 쏟기 위해 이 5분의 낭비를 제거하는 것임.
* **퍼실리데이팅 가이드**:
  - 오늘 1시간 투자해 자동화를 구축하면 앞으로 매달 수십 시간이 복리로 절약됨을 명확히 설명한다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

### 📌 [6] 클라우드 연동 권한과 공식 보안 프로토콜
* **관련 명세**: `이메일을 확인하고 스프레드시트에 옮겨 적고`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "자동화 도구에 내 이메일 비밀번호를 직접 타이핑해 주어야 하나요?"
* **자가진단 난관 지표**: 계정 비밀번호 유출 및 해킹에 대한 막연한 공포 때문에 연동 작업을 시작하지 못한다.
* **통과 기준 (이해 완료 판정)**:
  - 구글 등 플랫폼이 제공하는 공식 연동 토큰(OAuth 2.0 승인) 방식으로 비밀번호 없이 안전하게 연결됨을 안다.
* **퍼실리테이터 개입 가이드**: "비밀번호를 입력하는 것이 아니라 구글이 공식 중재하는 일시적 통행 승인 팝업을 거치는 것임을 상기시킨다."

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "제 이메일의 내용을 확인하고 복사해 오려면, 자동화 프로그램에 제 이메일 비밀번호를 직접 알려줘야 하나요? 해킹당하면 어쩌죠?"
* **학습자 난관**: 계정 연동(OAuth 인증) 과정에서 계정 보안과 비밀번호 누출에 대한 극심한 막연한 불안감을 가집니다.
* **기본 개념**: 
  - 걱정하지 마세요. 사용하시는 구글이나 이메일 비밀번호를 해당 사이트에 직접 텍스트로 적어 넘겨주는 것이 아님. 구글 시스템이 중간에서 공식 승인 창을 띄워 "이 자동화 프로그램이 내 편지를 읽을 수 있게 한시적으로 허용할까요?"라고 안전한 통행증을 중재(구글 인증)해 주기 때문에 안전하게 연동해 실습하실 수 있음.
* **퍼실리데이팅 가이드**:
  - 비밀번호를 입력하는 것이 아니라 구글이 공식 중재하는 일시적 통행 승인 팝업을 거치는 것임을 상기시킨다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

  - 과제 평가와 가입 승인에 아무 영향이 없는 일반 질문창이니 '개인 연습'이라 적고 빠르게 넘기라고 지시한다.
  - 교육생에게 바로 정답을 알려주기보다, 오류 메시지나 공식 가이드를 스스로 참고해 해결하도록 유도한다.

### 📌 [100] 브라우저 기본 인쇄 기능(Ctrl + P)을 이용한 PDF 파일 변환
* **관련 명세**: `비교 분석 보고서 (Markdown 또는 PDF)`

#### 👩‍🏫 이해도 체크 (Checklist)

* **자가진단 난관 지표**: 변환 툴이 컴퓨터에 없다고 패닉에 빠져 과제 마감 시간을 그대로 넘겨 실격당한다.
* **통과 기준 (이해 완료 판정)**:
