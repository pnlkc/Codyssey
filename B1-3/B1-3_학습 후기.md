## 학습후기
- Make와 Zapier는 기본적인 개념은 비슷하지만 세부적인 사용 방법이나 UI가 많이 달랐음
- n8n의 경우 별도의 설치가 필요하고 무료 사용이 불가능해 교육생들에게 소개하기는 어려워 보임
- 컴퓨터에 익숙하지 않은 교육생들이 Make나 Zapier를 사용하기에는 난이도가 상당히 높아보였음.
- 두 플랫폼 모두 영어가 익숙하지 않으면 사용이 어려워 보였음
- 두 플랫폼 모두 지원하는 기능이 매우 다양하여 교육생들이 자동화 플로우를 구성하는 과정에서 어떤 기능들을 사용하고 어떻게 조합하는지에 따라 다양한 어려움을 겪을 것으로 예상되었음

### 과제 진행 흐름
- Make와 Zapier를 사용한 자동화
- 구글 설문(이름과 취미를 받음) -> 취미에 "사냥"이 들어있는지 여부에 따라 구글 시트를 다르게 작성

### Make

- 자동화 실행 주기가 15분인 것으로 확인
- 자동화 블럭의 위치를 자유롭게 이동할 수 있음
- UI가 상대적으로 자유로워서 그런지 사용하기는 Make가 편한듯 보임
- 분기 처리를 If-else나 Router로 함
- 현재 시간이 미국 시간을 기준으로 작성되는 이슈가 있음 \<- 계정 설정의 Timezone 설정해도 안됨, {{addHours(var.scenario.executionStartedAt; 9)}} 형태의 명령어를 사용하면 됨

### Zapier

- 자동화 실행 주기가 거의 실시간으로 확인
- 자동화 블럭의 위치를 이동할 수 없음
- 분기 처리를 Path로 함
- 구글 시트에 헤더가 없는 경우 해당 칸을 감지하고 특정값을 입력할 수 없는 것으로 보임  
- 구글 시트 수정 후 테스트 실행을 해야 구글 시트의 변경이 감지되는 것으로 확인됨   
- 현재 시간이 미국 시간을 기준으로 작성되는 이슈가 있음 <- 계정 설정의 Timezone 설정하면 됨

    - [노코드 개념](https://cloud.google.com/discover/what-is-no-code?hl=ko)

### 3. 과제 목표
- 조건 분기의 용어나 방법이 툴마다 상이할 수 있다는 부분을 언급하면 좋을 듯 보임 (Make의 경우 Flow Control, Zapier의 경우 Flow Controls 내에 다양하게 존재함)

### 5. 보너스 과제
- 생성형 AI를 Action으로 추가해 사용하려면 API Key나 자동화 플랫폼 상의 토큰 등이 필요할 수 있고 과금 가능성이 있다는 부분을 언급해도 좋을 것 같음
- API Key에 대해 안내하기 전에 [API가 무엇인지](https://namu.wiki/w/API) 학습하도록 유도하고, 하단 `6. 제약 사항`에 나오는 API Key는 외부에 유출되면 안되는 중요한 정보라는 것을 강조하여 안내하는 것이 좋을 것 같음

### 6. 제약 사항
- `프로젝트 2는 Trigger 발생 시 자동 실행되어야 한다.` -> Make 툴의 무료 플랜의 경우 실시간으로 Trigger를 감지하지 않고 15분에 한번씩 감지한다는 언급 필요
- [Webhook에 대해 간단한 개념](https://docs.tosspayments.com/resources/glossary/webhook)을 확인하고 진행하도록 유도하는 것이 좋을 것 같음
