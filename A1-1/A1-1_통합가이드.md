## 🔍 1. 개발 환경 설정 및 기초 학습 파트

### 📌 [1] 파이썬 개발 환경 설정 및 버전 확인
* **관련 명세**: `VSCode에 Python 확장을 설치 / 터미널에서 Python 버전을 확인`

#### 👩‍🏫 이해도 체크 (Checklist)
* **확인 질문**: "설치된 파이썬의 버전이 3.10 이상인지 터미널에서 어떤 명령어로 확인할 수 있을까요?"
* **자가진단 난관 지표**: 터미널의 개념을 몰라 명령 프롬프트나 파워쉘 창을 여는 것부터 두려워하고, 파이썬이 설치되어 있음에도 환경 변수(Path) 미설정으로 인해 명령어를 찾을 수 없다는 에러를 겪음.
* **통과 기준 (이해 완료 판정)**:
  - `python --version`, `py --version` 또는 `python3 --version` 명령어를 터미널에 입력하여 버전을 정상 출력할 수 있다.
  - 파이썬 3.10 미만 버전일 경우 최신 문법(match-case 등)을 쓸 수 없음을 알고 있다.

### 📌 [6] 첫 커밋과 푸시 (`git add`, `git commit`, `git push`)

  - `git commit -m "메시지"`로 로컬 저장소에 영구 박제하고, `git push origin main`으로 업로드할 수 있다.
* **퍼실리테이터 개입 가이드**: "교육생에게 '우리가 쇼핑몰에서 살 물건들을 장바구니(`add`)에 담고, 최종 결제(`commit`)를 마친 후, 택배를 발송(`push`)하는 단계적 구조를 생각해보면 이해하기 쉬움'을 안내한다."
* **참고 레퍼런스**: [Git에 대하여](https://git-scm.com/about/) (사전지식: 없음)

#### 🙋‍♂️ 교육생 예상 질문 & 답변 (Q&A)
* **예상 질문**: "커밋 메시지에 오타를 냈습니다. 되돌리거나 수정하고 싶습니다."
* **학습자 난관**: 이미 생성된 최신 커밋 메시지의 수정법(`--amend`)을 알지 못함.
* **기본 개념**: 
  - 로컬에만 커밋이 있는 상태라면 `git commit --amend` 명령어를 통해 최신 커밋 메시지를 바로 덮어쓸 수 있음.
  - 하지만 푸시까지 이미 완료된 원격 커밋의 강제 수정은 히스토리 왜곡의 우려가 있으므로 초보자 단계에서는 새 커밋을 작성하여 푸시하는 것이 안전함.
* **퍼실리테이팅 가이드**:
  - 교육생에게 `git commit --amend -m "수정할 메시지"`를 안내하여 로컬 커밋 메시지를 수정하도록 지도한다. 단, 이미 Push까지 완료했다면 롤백 동의 규격에 따라 임의의 강제 푸시(`-f`)를 피하도록 주의를 준다.

* **참고 레퍼런스**: [점프 투 파이썬 - while 반복문](https://wikidocs.net/21) (사전지식: 없음)

* **학습자 난관**: 메서드 호출 시 괄호`()`를 누락하여 메서드 객체 자체를 참(True)으로 평가해 버리는 코딩 실수를 인지 못함.

* **관련 명세**: `main 브랜치 이외의 추가 브랜치를 생성하고 이 기능을 해당 브랜치에서 작업`

* **참고 레퍼런스**: [누구나 쉽게 이해하는 Git 브랜치 가이드](https://backlog.com/git-tutorial/kr/stepup/stepup1_1.html) (사전지식: 없음)

### 📌 [16] 프롬프트 목록 보기 및 즐겨찾기 표시 (`print_prompt`)
* **관련 명세**: `저장된 모든 프롬프트를 번호와 함께 출력 / 각 프롬프트의 제목, 카테고리, 즐겨찾기 여부(⭐)를 표시`

  - 문자열 결합 또는 f-string을 사용하여 즐겨찾기가 참(`True`)일 경우 끝에 `⭐` 아이콘을 출력하는 분기 처리를 구현한다.

* **참고 레퍼런스**: [파이썬 enumerate 함수 완벽 가이드](https://wikidocs.net/32#enumerate) (사전지식: for 반복문 기초)

### 📌 [17] 로컬 브랜치 병합 (`git checkout main`, `git merge`)

* **기본 개념**:

### 📌 [18] 카테고리별 조회 구현 (`print_category`)
* **관련 명세**: `선택하면 해당 카테고리의 프롬프트만 출력 / 해당 카테고리에 프롬프트가 없으면 안내 메시지를 출력`

* **학습자 난관**: 삭제로 리스트 인덱스가 당겨졌음에도 기존 고정 인덱스 번호를 유지하려다 생기는 착시.
* **기본 개념**: 
  - 리스트는 물리적인 중간 원소가 지워지면(`del prompts[idx]`) 뒷부분의 방 번호가 자동으로 하나씩 앞으로 땡겨져 채워짐.

## 🐍 7. 사용된 파이썬 핵심 개념 & 함수 가이드

이 영역은 `main.py` 파일의 프롬프트 관리 프로그램에 사용된 핵심적인 파이썬 개념과 내장 함수들을 정리한 가이드입니다.

### 1. 핵심 파이썬 개념 (Core Concepts)

#### ① 클래스와 객체 (`class`, `__init__`, `self`)
* **개념:** 클래스는 객체를 만들기 위한 **'설계도'** 혹은 **'틀(예: 붕어빵틀)'**이고, 객체(인스턴스)는 그 설계도로부터 실제로 만들어진 **'결과물(예: 붕어빵)'**입니다.
* **`__init__` (초기화 메서드):** 객체가 생성될 때 자동으로 호출되어 객체의 초기 변수(값)를 세팅해 주는 특수한 함수입니다.
* **`self`:** '나 자신'을 가리킵니다. 객체 내부에서 자기 자신의 변수나 함수에 접근할 때 항상 첫 번째 매개변수로 사용합니다.
* **코드 예시:**
  ```python
  class Prompt:
      def __init__(self, title: str, content: str, category: int, favorite: bool = False):
          self.title = title       # 객체의 제목 변수 설정
          self.content = content     # 객체의 내용 변수 설정
          self.category = category   # 객체의 카테고리 변수 설정
          self.favorite = favorite   # 객체의 즐겨찾기 상태 설정 (기본값 False)
  
  # 객체 생성하기 (설계도로 붕어빵 찍어내기)
  my_prompt = Prompt('블로그 도우미', '내용...', 1)
  print(my_prompt.title)  # 출력: 블로그 도우미
  ```

#### ② 리스트 컴프리헨션 (List Comprehension)
* **개념:** 기존 리스트를 바탕으로 조건에 맞는 새로운 리스트를 **단 한 줄**로 명료하고 빠르게 만들어내는 파이썬의 독특하고 강력한 문법입니다.
* **비유:** "기존 프롬프트 목록(`prompts`)에서 카테고리가 일치하는 애들만 쏙쏙 뽑아 새로운 리스트를 만들어줘"라는 지시를 한 줄로 줄여 쓰는 지름길입니다.
* **코드 예시:**
  ```python
  # 일반적인 for 루프 방식
  filtered = []
  for p in prompts:
      if p.category == 1:
          filtered.append(p)

  # 리스트 컴프리헨션 방식 (동일한 동작)
  filtered = [p for p in prompts if p.category == 1]
  ```

#### ③ 삼항 연산자 (Conditional Expression)
* **개념:** 간단한 `if-else` 조건문을 한 줄로 간결하게 표현하여 문자열이나 변수에 즉시 대입할 때 유용하게 쓰입니다.
* **문법:** `참일_때의_값 if 조건 else 거짓일_때의_값`
* **코드 예시:**
  ```python
  # 즐겨찾기가 되어 있으면 '⭐'를, 아니면 빈 문자열('')을 반환
  star = '⭐' if prompt.favorite else ''
  ```

#### ④ 진입점 조건문 (`if __name__ == "__main__":`)
* **개념:** 이 파이썬 파일이 직접 실행되었을 때만 특정 코드 블록(예: `main()` 함수)을 작동시키겠다는 의미의 표준 관례입니다.
* **이유:** 다른 파일에서 이 파일을 가져와(import) 사용할 때, 원치 않게 메인 프로그램이 자동으로 켜지는 것을 방지합니다.

### 2. 자주 사용되는 파이썬 내장 함수 & 메서드 (Built-in Functions)

#### ① `print(...)`
* **설명:** 모니터 화면에 문자나 숫자 등의 데이터를 출력합니다.
* **옵션 `end=''`:** 기본적으로 `print()`는 호출될 때마다 자동 줄바꿈을 수행합니다. 만약 줄바꿈 없이 이어서 출력하고 싶다면 `end=''`를 사용합니다.
  ```python
  print('검색어: ', end='')
  keyword = input() # 검색어: [입력대기] 와 같이 줄바꿈 없이 입력 창이 뜸
  ```

#### ② `input()`
* **설명:** 사용자로부터 키보드 입력값을 한 줄 받아옵니다. 이때 입력받은 데이터는 항상 **문자열(String)** 타입으로 저장됩니다.

#### ③ `int(...)`
* **설명:** 소수점이나 문자열 형태의 숫자를 **정수형(Integer)** 데이터로 변환합니다.
* **주의:** `input()`으로 입력받은 값은 문자열이므로 숫자로 활용하여 크기 비교 등을 수행하려면 `int()`로 형변환을 꼭 거쳐야 합니다.
  ```python
  select = input()       # 사용자가 '5' 입력 -> select는 문자열 "5"가 됨
  number = int(select)   # 문자열 "5"를 숫자 5로 변경
  ```

#### ④ `len(...)`
* **설명:** 리스트(목록)의 총 원소 개수나 문자열의 글자 길이를 구합니다.
  ```python
  total_count = len(prompts) # prompts 리스트 안에 들어있는 프롬프트 객체 개수 반환
  ```

#### ⑤ `enumerate(...)`
* **설명:** 리스트 등의 목록을 순회할 때, 현재 원소가 몇 번째인지를 나타내는 **인덱스 번호**와 **원소의 값**을 동시에 제공해 줍니다.
* **옵션 `start=1`:** 인덱스 번호를 `0`부터가 아닌 `1`부터 매겨 출력하게 설정할 수 있습니다.
  ```python
  for i, prompt in enumerate(prompts, start=1):
      print(f"{i}번 프롬프트: {prompt.title}")
  ```

#### ⑥ `str.isdigit()`
* **설명:** 문자열 변수가 **오직 숫자로만 구성되어 있는지**를 확인하여 참(`True`) 또는 거짓(`False`)을 반환합니다.
* **용도:** 사용자가 메뉴 선택 시 숫자가 아닌 오타를 입력했을 때 크래시를 예방하기 위해 사용합니다.
  ```python
  select = "abc"
  print(select.isdigit())  # 출력: False
  ```
