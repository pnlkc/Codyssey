
## 학습 후기
### 1차 실행 (Gemini + Runway + Vrew / Google Flow)
- 명세서에 이미지 생성 예시가 Midjourney로 나와 있는데 현재 Midjourney는 무료로 사용이 불가능함 -> 구글 Gemini를 사용하여 이미지를 생성하였음
- 비디오 변환 예시로 나온 Runway는 무료 플랜의 경우 이미지 생성을 5, 10초 단위로만 생성이 가능하고 비디오 사이즈를 720p까지 생성이 가능한듯 보임
- Runway의 경우 1,000자까지 허용해주고 있지만 긴 프롬프트의 경우 준수율이 떨어지는 모습을 보임. 추가로 한글 프롬프트의 경우에도 준수율이 떨어짐. 최종적으로 간단한 영어 프롬프트를 통해 스마트워치를 손가락으로 터치하는 결과물을 얻을 수 있었음
- 오디오 생성 예시인 Suno의 경우 5~10초의 짧은 오디오 생성이 불가능했음 -> 구글 Gemini를 사용하여 오디오를 생성하였음
- 영상 편집 소프트웨어는 웹상에서 편집이 가능한 [Vrew](https://vrew.ai/ko/)를 사용하였음
- 구글 Flow를 사용하면 이미지 -> 영상 + 음성 -> 편집 기능이 전부 가능하였음 (무료 버전의 경우 50크레딧을 주는데 영상 1개 생성에 veo 3.1은 10크레딧, omni는 15크레딧을 소모하였음, 유료 버전의 경우 1,000크레딧이 제공되어 여유롭게 생성 가능)


### 2차 실행 (네이토, Vrew)
- 해당 학습은 네이토에 추가된 기능을 중심으로 학습을 진행하였음
- 네이토는 이미지를 베이스로 영상을 생성하는 기능을 제공하지 않아 이미지 생성 후 영상 생성 로직을 사용하지 않고 바로 영상 생성을 진행하였음
- 비디오 생성의 기본으로 설정된 OpenAI의 Sora2 모델은 화질이 좋지는 않은 것으로 보임
- 네이토의 영상 생성에는 음성이 포함되어 생성되고 있음 
- 개별 영상을 합치는 툴은 구글 Flow를 사용하려 했으나 "장면을 내보낼 수 없습니다"라는 오류가 발생하여 Vrew를 사용하여 합쳤음
- 네이토에서 저작권이 있는 케릭터를 생성하려 하면 오류가 뜨면서 생성되지 않았지만 저작권으로 인해 생성이 안된다는 등의 안내가 있어 교육생들이 계속 재시도할 가능성이 있음
- 네이토에서 이미지, 음성, 영상 제작시 목록이 스크롤이 되지 않아 생성 버튼이 가려지는 문제가 있음


## 명세서 관련 내용
### 1. 미션 소개
- `이번 미션의 목표는 기획 의도가 프롬프트를 거쳐 최종 영상으로 구현되기까지의 전체 제작 파이프라인을 스스로 설계하는 데 있습니다.` -> 만약 B1-1을 학습하지 않고 해당 과제부터 학습하는 경우 B1-1이 프롬프트 관련 과제이므로 먼저 학습하도록 안내
- 실제 브랜드를 사용하여 과제 진행시 `6. 제약 사항`에 안내된 부분처럼 저작권 이슈를 고려하도록 안내 

### 2. 최종 결과물
- 광고 영상 파일 길이가 10초 이내로 나오는데 `4. 기능 요구 사항`에서는 `최종 영상은 초 이상 60초 이내로 제작한다.`라고 나오는 부분 해결 필요

### 4. 기능 요구 사항
- 네이토 영상 생성의 경우 사운드가 포함되어 출력되긴 하나 오디오 생성 AI를 사용해보는 것이 과제 목표이므로 오디오 생성 AI를 사용해보도록 유도하는 것이 좋을 것 같음

### 6. 제약 사항
- `Premiere Pro`의 경우 무료로 사용 불가하고 별도로 설치해서 사용해야 하여 사용 불가함
- [ControlNet](https://github.com/lllyasviel/controlnet)이나 [Ip-Adapter](https://github.com/tencent-ailab/IP-Adapter)에 대한 개념을 학습하도록 유도하면 좋을 것 같음
- [Stable Diffusion](https://stability.ai/stable-image)에 대해 학습해보도록 안내해도 좋을 것 같음. [참고자료2](https://wikidocs.net/234116) 
- [WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui)나 [CompyUI](https://comfy.org/), [Diffusers](https://huggingface.co/docs/diffusers/ko/index) 등 이미지 생성 AI 소프트웨어/라이브러리를 소개하는 것도 좋을 것 같음
