# ConceptNote AI 서비스 기획서 (Service Plan)

---

## 1. 서비스 개요

- **서비스명**: ConceptNote AI (AI 스마트 개념 학습 메모장)
- **타겟 사용자**:
  - IT/프로그래밍 전공 학생, 취업 준비생, 신기술 개념을 빠르게 파악하고자 하는 개발자 및 직장인
- **기획 목적**:
  - 기존의 긴 설명글이나 검색 결과를 매번 탐색할 필요 없이, 키워드 하나로 핵심 요약·주요 특징·쉬운 비유·예시 코드가 완비된 규격화된 개념 노트를 실시간으로 자동 작성해 주는 나만의 학습 메모장을 제공합니다.

---

## 2. 페이지 및 섹션 구성 (4개 주요 섹션)

1. **Hero / 서비스 소개 섹션 (`#hero`)**:
   - 비주얼 브랜드 헤더, 핵심 슬로건, 특징 통계(100% 자동 구조화, 실시간 생성, 로컬 저장 메모장) 및 주요 CTA 버튼 배치
2. **AI 개념 노트 생성 섹션 (`#generate`)**:
   - 키워드 입력 필드, 설명 난이도 선택(초급/중급/심화) 폼, 생성 버튼, 로딩 스피너 UI, AI 개념 카드 출력 영역
3. **내 저장 메모장 섹션 (`#notes`)**:
   - 생성된 노트를 `localStorage`에 보관하여 카드 형태로 모아보는 그리드 UI, 단건 삭제 및 전체 삭제 기능
4. **FAQ 섹션 (`#faq`)**:
   - 서비스 이용 방법, 저장 방식, 오류 대처 등에 대한 자주 묻는 질문 접이식 Accordion UI

## 3. AI 기능 설계 (입력 / 처리 / 출력 / 예외 처리)

### (1) 입력 (Input)
- **`keyword` (필수)**: 학습하고자 하는 단어 또는 용어 (예: `REST API`, `클로저`, `Docker`, `양자컴퓨팅`)
- **`level` (선택)**: 초급(쉬운 비유 중심) / 중급(핵심 개념 & 특징) / 심화(실무 활용 & 예시 코드)

### (2) 처리 (Process)
- 프론트엔드 `js/app.js`에서 `fetch('/api/explain')` 비동기 POST 요청 전송
- Vercel Serverless Function `api/explain.py`에서 Google Gemini API (`gemini-3.5-flash-lite`) 호출
- JSON 강제 프롬프트를 통해 구조화된 JSON 데이터 반환

### (3) 출력 (Output)
- **`keyword`**: 입력된 키워드
- **`level`**: 선택된 난이도
- **`definition`**: 2~3문장의 명확한 개념 정의
- **`features`**: 3가지 핵심 특징 리스트
- **`analogy`**: 일상생활에 비유한 이해하기 쉬운 비유 설명
- **`example`**: 실무 활용 예시 코드 또는 적용 사례

### (4) 실패 및 예외 처리 기준 (UX 정책)
- **빈 입력(필수값 누락)**:
  - 사용자가 키워드를 입력하지 않고 제출 시 폼 제출을 차단하고 "⚠️ 학습할 키워드를 입력해 주세요." 토스트 알림 표시
- **API 오류 (4xx/5xx) & 네트워크 지연**:
  - API 호출 실패 시 에러 경고 상자 및 "❌ 생성 실패: 서버 응답 오류" 토스트 안내 출력
  - 백엔드에서는 기본 Fallback 가이드 노트를 구성하여 서비스 전체가 다운되는 상황 방지

---

## 4. 보안 및 운영 관리 방안

- **API 키 관리**: `GEMINI_API_KEY`는 코드나 클라이언트에 절대 노출되지 않으며, Vercel Serverless Function 환경 변수로만 관리
- **로컬 스토리지 데이터 관리**: 개인 저장 노트는 클라이언트 브라우저 `localStorage`에 관리되어 서버 비용 및 DB 수용 부담 없음
